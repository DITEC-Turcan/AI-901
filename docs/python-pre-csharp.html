Argumenty metód — na toto pozor

Pomenované argumenty sú v Pythone norma

client.analyze(
    image_data=image,
    visual_features=[VisualFeatures.CAPTION, VisualFeatures.TAGS],
)

To isté ako named arguments v C#: client.Analyze(imageData: image, visualFeatures: […]). V C# sú skôr výnimka, v Pythone sa používajú takmer vždy.

**kwargs — slovník rozbalený na argumenty

kwargs = {"input": [...], "extra_body": agent_reference}
if previous_response_id:
    kwargs["previous_response_id"] = previous_response_id

response = openai_client.responses.create(**kwargs)

Dve hviezdičky pred slovníkom znamenajú „každý kľúč použi ako názov parametra“. V C# priamy ekvivalent neexistuje — musel by si buď mať overload, alebo nastaviť vlastnosť options objektu podmienene. Zmysel tohto vzoru: parameter previous_response_id sa pošle len pri druhom a ďalšom kole konverzácie.

Truthiness — najčastejší zdroj nedorozumenia

Python berie za „nepravdivé“ nielen False a None, ale aj prázdny reťazec, prázdny zoznam, prázdny slovník a nulu.

Python Čo to naozaj testuje

if not user_input: continue preskoč prázdny riadok
if not result.objects.list: zoznam je prázdny → .Count == 0

Udalosti: .connect() namiesto +=

Python (lesson5-3) C# 
def on_recognized(evt):
    print(evt.result.text)

recognizer.recognized.connect(on_recognized)
 
recognizer.Recognized += (s, e) =>
    Console.WriteLine(e.Result.Text);

on_recognized je lokálna funkcia definovaná vnútri main() — presne ako local function v C#, vrátane toho, že vidí premenné z obklopujúcej metódy (closure). Funkcia sa odovzdáva bez zátvoriek (connect(on_recognized)), so zátvorkami by sa zavolala.

Asynchrónnosť a long-running operácie

Všetkých šesť skriptov je synchrónnych — žiadne async/await. Vlákno jednoducho čaká. V .NET by si písal await client.AnalyzeAsync(...).

Kompletný príklad: lesson4-2 v C#

Ten istý program, aby si videl kostru naraz.

var conversation = new List<object>
{
    new { role = "system", content = systemPrompt }
};

while (true)
{
    Console.Write("You: ");
    var userInput = Console.ReadLine()?.Trim();
    if (string.IsNullOrEmpty(userInput)) continue;

    conversation.Add(new { role = "user", content = userInput });

Cvičné otázky na čítanie kódu

Presne ten typ úrovne, aký sa očakáva na AI-901 — nie písať, ale rozumieť.

  1. Čo vráti os.getenv("SYSTEM_PROMPT", "You are a helpful assistant."), ak premenná SYSTEM_PROMPT neexistuje?

    • A. None
    • B. Prázdny reťazec
    • C. "You are a helpful assistant."
    • D. Vyhodí výnimku
    Ukázať odpoveď

    C. Druhý argument je predvolená hodnota — ako ?? "default" v C#.

  2. Podmienka if not value: je pravdivá pre ktoré hodnoty? Vyber všetky správne.

    • A. None
    • B. ""
    • C. "abc"
    • D. []
    Ukázať odpoveď

    A, B a D. Python považuje za nepravdivé aj prázdny reťazec, prázdny zoznam, prázdny slovník a nulu. Ekvivalent if not value pre reťazec je string.IsNullOrEmpty(value), nie value == null.

  3. Čo robí [{"role": "user", "content": text}]?

    • A. Vytvorí triedu s dvoma vlastnosťami.
    • B. Vytvorí zoznam s jedným slovníkom — obdoba new List<object> { new { role = "user", content = text } }.
    • C. Vytvorí dva samostatné zoznamy.
    • D. Ide o tuple dvoch hodnôt.
    Ukázať odpoveď

    B. Hranaté zátvorky = zoznam, zložené = slovník. JSON payload sa v Pythone skladá práve z týchto dvoch stavebných prvkov.

  4. Čo znamenajú dve hviezdičky v responses.create(**kwargs)?

    • A. Násobenie.
    • B. Rozbalenie slovníka na pomenované argumenty metódy.
    • C. Odovzdanie odkazom (ako ref).
    • D. Asynchrónne volanie.
    Ukázať odpoveď

    B. Každý kľúč slovníka sa použije ako názov parametra. V lesson4-4 to slúži na to, aby sa previous_response_id poslal len od druhého kola konverzácie. Priamy ekvivalent v C# neexistuje.

  5. Na čo slúži with open(path, "rb") as f:?

    • A. Otvorí súbor na čítanie v binárnom režime a po opustení bloku ho automaticky zavrie.
    • B. Vytvorí nový súbor.
    • C. Zašifruje obsah súboru.
    • D. Načíta súbor asynchrónne.
    Ukázať odpoveď

    A. with == using. "rb" = read binary — vracia bytes (≈ byte[]), čo je presne to, čo SDK očakáva pri odosielaní obrázkov a dokumentov.

  6. sorted(result.sentences, key=lambda s: s.offset) — čo je ekvivalent v C#?

    • A. sentences.Where(s => s.Offset)
    • B. sentences.OrderBy(s => s.Offset)
    • C. sentences.Select(s => s.Offset)
    • D. sentences.GroupBy(s => s.Offset)
    Ukázať odpoveď

    B. key= je selektor triedenia, lambda s: s.offset je s => s.Offset.

  7. Prečo sa v recognizer.recognized.connect(on_recognized) uvádza funkcia bez zátvoriek?

    • A. Je to preklep.
    • B. Odovzdáva sa odkaz na funkciu; so zátvorkami by sa funkcia hneď zavolala.
    • C. Funkcia nemá parametre.
    • D. Zátvorky sa v Pythone nikdy nepíšu.
    Ukázať odpoveď

    B. Rovnaký princíp ako recognizer.Recognized += OnRecognized; v C# — priraduje sa handler, nie výsledok jeho volania.

  8. Čo robí result.tags.list[:5]?

    • A. Vráti päť náhodných prvkov.
    • B. Vráti prvých päť prvkov — ako .Take(5).
    • C. Vráti prvok s indexom 5.
    • D. Odstráni prvých päť prvkov.
    Ukázať odpoveď

    B. Slicing [start:stop]; vynechaný start znamená od začiatku. [-1] by bol posledný prvok.

  9. Prečo je na konci skriptu if __name__ == "__main__": main()?

    • A. Je to povinná syntax každého Python súboru.
    • B. Zabezpečí, že sa main() spustí len pri priamom spustení súboru, nie pri jeho importe.
    • C. Definuje názov programu.
    • D. Spustí program asynchrónne.
    Ukázať odpoveď

    B. Ekvivalent static void Main(). Python inak vykoná celý súbor zhora nadol — aj pri importe ako knižnica.

  10. V kóde je fields = result.contents[0].fields or {}. Prečo?

    • A. Aby sa vytvoril prázdny slovník, keď fields je None alebo prázdne — a následná iterácia nespadla.
    • B. Aby sa slovník vymazal.
    • C. Aby sa polia zlúčili s prázdnym slovníkom.
    • D. Ide o logický OR nad boolean hodnotami.
    Ukázať odpoveď

    A. Blízke k ?? new Dictionary<,>(), ale v Pythone zachytí aj prázdny slovník, nielen None.
