AI-901 — dokumentácia demo príkladov

Čo presne robia Python skripty v tomto repozitári a ako súvisia so skúškou Microsoft Azure AI Fundamentals (AI-901).

Ako použiť túto dokumentáciu

Každý adresár lessonX-Y obsahuje jeden malý, samostatne spustiteľný Python skript, ktorý demonštruje jednu skupinu schopností Azure AI / Microsoft Foundry. Pre každý z nich existuje samostatná stránka s rozborom kódu riadok po riadku, so sekciou „Čo z toho treba na skúšku“ a s cvičnými otázkami vo formáte skúšky (výber z možností, odpoveď s vysvetlením sa odkryje kliknutím).

Skúška AI-901 nie je o písaní kódu spamäti, ale o tom, že rozumieš, ktorá služba rieši ktorý problém, aký je tok volania a čo znamenajú kľúčové parametre. Sekcie označené fialovou farbou presne toto zvýrazňujú.

Prichádzaš z C#?

Začni stránkou Python pre C# programátora — prekladá do C# každú konštrukciu, ktorá sa v týchto skriptoch vyskytuje (odsadenie namiesto zátvoriek, slovníky namiesto anonymných objektov, **kwargs, truthiness, with vs. using, poller vs. Operation<T>).

Spoločné vzory vo všetkých skriptoch

Všetkých šesť skriptov je napísaných podľa rovnakej kostry. Ak ju pochopíš raz, každé ďalšie demo je už len výmena SDK a metódy. 

load_config()      # načíta config.env cez python-dotenv, ak chýba → ukončí sa
get_required(key)  # prečíta povinnú premennú, ak chýba → zrozumiteľná chyba
build_client()     # zostaví klienta: endpoint + credential (+ verzia API / model)
<volanie služby>   # jedna alebo viac metód SDK
<výpis výsledku>   # čitateľný výstup do konzoly

Dva spôsoby autentifikácie, ktoré sa opakujú

Spôsob Kód Použité v Kedy
Kľúč (API key) AzureKeyCredential(key), resp. api_key= 4-2, 5-1, 5-3, 6-3, 7-4 rýchly štart, demo, testy
Microsoft Entra ID DefaultAzureCredential() 4-4 produkcia — žiadne tajomstvá v konfigurácii
Na skúšku

Otázka typu „ktorý spôsob autentifikácie je odporúčaný / najbezpečnejší?“ má takmer vždy odpoveď Microsoft Entra ID (managed identity / DefaultAzureCredential), nie kľúč. Kľúče sa dajú rotovať, ale musia sa niekde uložiť; Entra ID identita sa neukladá nikam.

cd lesson5-1
