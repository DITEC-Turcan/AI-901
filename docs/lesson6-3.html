lesson6-3 — Vision: popis, detekcia objektov a OCR

lesson6-3/vision.py — tri schopnosti Azure AI Vision na troch lokálnych obrázkoch.

Čo skript robí

Načíta tri obrázky ležiace vedľa skriptu a na každom spustí inú vizuálnu schopnosť:

Súbor Visual feature Výstup
example1.png CAPTION + TAGS jedna veta popisujúca obrázok + top 5 tagov, oboje so skóre
example2.png OBJECTS zoznam objektov s názvom, skóre a bounding boxom
example3.png READ text nájdený v obrázku (OCR), po riadkoch

Obrázky nie sú v repozitári — treba doplniť vlastné s týmito názvami.

Rozbor kódu

1. Klient

client = ImageAnalysisClient(
    endpoint=endpoint,
    credential=AzureKeyCredential(key),
)

Jeden klient obslúži všetky tri úlohy. Ide o Image Analysis 4.0 API.

2. Jedna metóda, prepínač je visual_features

result = client.analyze(
    image_data=image,                       # bajty lokálneho súboru
    visual_features=[VisualFeatures.CAPTION, VisualFeatures.TAGS],
)

Toto je jadro celého dema. Vždy sa volá tá istá metóda analyze(); čo sa vlastne stane, určuje zoznam visual_features. Dá sa ich vyžiadať viac naraz v jednom volaní — každá vyplní svoju vlastnosť výsledku (result.caption, result.tags, result.objects, result.read, …). Nevyžiadané vlastnosti zostanú None, preto sa v kóde všade kontrolujú.

Pre obrázok z internetu existuje varianta analyze_from_url(image_url=...) namiesto image_data.

3. Popis a tagy

print(f"It looks like: {result.caption.text} (confidence {result.caption.confidence:.2f})")
for tag in result.tags.list[:5]:
    print(f"  - {tag.name} (confidence {tag.confidence:.2f})")

Caption je jedna veta v ľudskej reči popisujúca celú scénu („a dog sitting on a couch“). Tags sú slová opisujúce objekty, prostredie a činnosti na obrázku, zoradené podľa skóre. Skript vypíše len prvých päť.

4. Detekcia objektov a bounding boxy

for obj in result.objects.list:
    name = obj.tags[0].name
    confidence = obj.tags[0].confidence
    box = obj.bounding_box
    print(f"{name} ({confidence:.2f}) at x={box.x}, y={box.y}, "
          f"width={box.width}, height={box.height}")

Rozdiel oproti tagom: detekcia objektov vracia aj polohu. bounding_box má štyri čísla — x, y (ľavý horný roh) a width, height v pixeloch. Vďaka tomu sa dá do obrázka vykresliť rámček.

5. OCR cez READ

for block in result.read.blocks:
    for line in block.lines:
        print(f"  {line.text}")

Výsledok má hierarchiu blocks → lines → words. Skript vypisuje úroveň riadkov; každé slovo má navyše vlastné skóre a polygón polohy. Feature READ je nástupca staršieho OCR API a zvláda tlačený aj písaný text.

Čo z toho treba na skúšku

Domény: Identify AI workloads („features and capabilities of computer vision“) a Implement AI solutions with computer vision … by using Foundry („Build a lightweight application that includes vision capabilities“).

  • Rozlíš štyri úlohy — toto je najčastejší typ otázky z tejto oblasti:
    • Image classification — jedna kategória pre celý obrázok.
    • Object detection — čo a kde, s bounding boxom.
    • Semantic segmentation — klasifikácia na úrovni jednotlivých pixelov.
    • OCR — čítanie textu z obrázka.
  • Tagy vs. detekcia objektov. Tagy povedia, že na obrázku je pes. Detekcia navyše povie kde a koľko psov. Ak otázka spomína súradnice alebo počítanie výskytov, odpoveď je detekcia objektov.
  • Caption vs. dense captions. Caption = jedna veta pre celý obrázok; dense captions = samostatný popis pre každú oblasť.
  • Prebuilt vs. custom. Toto demo používa hotové modely. Pre vlastné kategórie (napr. typy výrobkov na linke) sa použije custom image classification alebo custom object detection s vlastnými označenými dátami.
  • Face vs. Vision. Rozpoznávanie a porovnávanie tvárí rieši samostatná služba Azure AI Face, ktorá má navyše obmedzený prístup kvôli zodpovednej AI. Image Analysis vie tváre len nájsť.
  • OCR vs. Content Understanding / Document Intelligence. OCR vráti text. Ak potrebuješ štruktúrované polia (číslo faktúry, dátum, suma), ide o extrakciu informácií — pozri lesson7-4.
Typická otázka

Treba spočítať, koľko áut je na zábere z parkoviska, a zvýrazniť ich.
→ Object detection (bounding boxy).

Treba len zistiť, či fotka zobrazuje pláž alebo hory.
→ Image classification.

Treba prečítať evidenčné číslo z fotky auta.
→ OCR / feature READ.

Treba automaticky vygenerovať alt text pre obrázky na webe (inkluzívnosť).
→ Caption.

Cvičné otázky

Odpoveď a vysvetlenie odkryješ kliknutím na „Ukázať odpoveď“.

  1. Treba spočítať autá na zábere z parkoviska a v obrázku ich zvýrazniť rámčekom. Ktorá úloha počítačového videnia to je?

    • A. Image classification
    • B. Object detection
    • C. Semantic segmentation
    • D. OCR
    Ukázať odpoveď

    B. Detekcia objektov vracia čo aj kde — bounding box so súradnicami x, y, width, height. Ak otázka spomína súradnice, rámčeky alebo počítanie výskytov, odpoveď je vždy detekcia objektov.

  2. Stačí ti zistiť, či fotografia zobrazuje pláž, hory alebo mesto — jedna kategória na celý obrázok.

    • A. Image classification
    • B. Object detection
    • C. Facial recognition
    • D. OCR
    Ukázať odpoveď

    A. Klasifikácia priradí obrázku ako celku jednu (alebo viac) kategórií, bez informácie o polohe.

  3. Ktorá úloha priraďuje kategóriu každému jednotlivému pixelu?

    • A. Object detection
    • B. Image classification
    • C. Semantic segmentation
    • D. Tagging
    Ukázať odpoveď

    C. Segmentácia je najjemnejšia granularita — používa sa napr. v medicínskom zobrazovaní alebo pri autonómnom riadení.

  4. Aký je rozdiel medzi TAGS a OBJECTS?

    • A. Žiadny, len iný formát výstupu.
    • B. Tagy hovoria, čo na obrázku je; detekcia objektov navyše kde a koľkokrát.
    • C. Tagy fungujú len na fotografie, objekty len na kresby.
    • D. Objekty nevracajú confidence score.
    Ukázať odpoveď

    B. Tag „dog“ znamená „na obrázku je pes“. Detekcia vráti bounding box pre každého psa zvlášť, takže sa dajú spočítať aj lokalizovať.

  5. Treba prečítať evidenčné číslo z fotografie auta. Ktorý visual feature?

    • A. CAPTION
    • B. OBJECTS
    • C. READ
    • D. SMART_CROPS
    Ukázať odpoveď

    C. READ je OCR — nástupca staršieho OCR API, zvláda tlačený aj rukou písaný text. Výsledok má hierarchiu blocks → lines → words.

  6. Pre lepšiu prístupnosť webu treba ku každému obrázku automaticky vygenerovať alt text — jednu vetu popisujúcu scénu.

    • A. TAGS
    • B. CAPTION
    • C. READ
    • D. PEOPLE
    Ukázať odpoveď

    B. Caption je jedna veta v ľudskej reči pre celý obrázok. Dense captions by vrátili samostatný popis pre každú oblasť. Toto je zároveň učebnicový príklad princípu inclusiveness zo zodpovednej AI.

  7. Výrobná linka potrebuje rozpoznávať vlastné typy súčiastok, ktoré prebuilt model nepozná. Čo použiješ?

    • A. Custom image classification alebo custom object detection s vlastnými označenými dátami.
    • B. Zvýšenie rozlíšenia obrázkov.
    • C. Feature READ.
    • D. Azure AI Face.
    Ukázať odpoveď

    A. Prebuilt modely poznajú bežné objekty. Pre doménovo špecifické kategórie treba vlastný model natrénovaný na označených dátach.

  8. Aplikácia má porovnávať tváre a overovať totožnosť osôb. Ktorá služba?

    • A. Azure AI Vision — Image Analysis
    • B. Azure AI Face
    • C. Azure AI Language
    • D. Azure AI Content Understanding
    Ukázať odpoveď

    B. Image Analysis vie tváre len nájsť. Rozpoznávanie a porovnávanie identity rieši samostatná služba Face, ktorá má navyše obmedzený prístup (Limited Access) kvôli princípom zodpovednej AI.

  9. Koľko volaní analyze() treba, ak chceš z jedného obrázka naraz caption, tagy aj text?

    • A. Tri — jedno na každú schopnosť.
    • B. Jedno, so všetkými troma hodnotami v visual_features.
    • C. Dve — OCR musí byť vždy samostatne.
    • D. Závisí od veľkosti obrázka.
    Ukázať odpoveď

    B. visual_features je zoznam. Každá vyžiadaná schopnosť vyplní svoju vlastnosť výsledku; nevyžiadané zostanú None, preto ich kód kontroluje.

  10. Obrázky sú uložené v Azure Blob Storage a dostupné cez URL. Ako sa zmení volanie?

    • A. Nijako, image_data prijíma aj URL.
    • B. Použije sa analyze_from_url(image_url=...).
    • C. Obrázky treba najprv skonvertovať na base64 reťazec.
    • D. Treba iný typ zdroja v Azure.
    Ukázať odpoveď

    B. SDK ponúka dve varianty: bajty lokálneho súboru (image_data) alebo verejne dostupnú URL.

  11. Z naskenovaných faktúr potrebuješ získať číslo faktúry, dátum splatnosti a celkovú sumu ako pomenované polia. Stačí OCR?

    • A. Áno, READ vráti polia priamo.
    • B. Nie — OCR vráti len text; na štruktúrované polia treba Content Understanding.
    • C. Nie, treba custom image classification.
    • D. Áno, ale len pri PDF súboroch.
    Ukázať odpoveď

    B. Toto je hranica medzi dvoma službami a častý zdroj zámeny — pozri lesson7-4.
